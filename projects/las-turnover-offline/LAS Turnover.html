Connect a turnover data file

Choose a JSON file in your locally synced OneDrive / SharePoint folder. Changes will save to that file; OneDrive handles syncing it. The HTML and Excel source are not changed.

One editor at a time. A synced folder does not support reliable simultaneous editing. This app checks for changed files before saving, but that cannot prevent every sync conflict between computers. Wait for OneDrive to finish syncing before handing over editing.

Choose Connect folder (data + log) to autosave both files. The first connection creates the files; later connections load them. The single-file options below save history inside the JSON, with CSV available through Change log → Export. Choose New data file for single-file setup. Other users choose Open existing data file and select the same synced JSON. Reconnect each time you open the app. Keep backup copies for each shift.

Using LAS Turnover

Double-click a cell, press Enter, or choose Edit cell. Dropdowns and dates use the workbook’s formats. Calculated cells update automatically and cannot be overwritten. Arrow keys and Tab move between cells.

Open → Automated: use the copy button to take a snapshot of Open Turnover. Edit Automated independently to arrange the display. Workload reads from Automated. Later Open edits reach Automated only when you copy again.

Saving: enter your editor name, then choose Connect data file → Connect folder (data + log) to select your synced OneDrive folder. The app writes the data JSON and CSV change log after each applied edit. Reconnect the folder each time you open the app. Without a connected folder, changes save automatically in this browser on this device, like AeroLog. They do not update the Excel file or the HTML file. Save a backup JSON into your folder at the end of a shift. Restore it to move between browsers or computers. A shared folder does not synchronize browser data.

Before moving the app: save a backup first. Keep the HTML file in a consistent location and use the same browser profile. Clearing browser data or using private browsing can remove local records.

Workbook behavior: the original calculation meanings and conditional styles are retained. Aircraft and deferral totals now cover all active sections and added rows, correcting the template’s incomplete total ranges. Division by zero displays #DIV/0! as in Excel. The Workload TECHS count follows the template’s text-count formula; its original “d” entries are retained. The Summary tab is manual, as in the source.

Display: Fit width shows the full sheet; increase zoom for editing. Print / PDF prints the active sheet. Testing tabs are hidden reference copies by default. Use the + / − controls on workload and deferral headings to add or remove rows; Aircraft controls add or remove the last section. Removal requires empty entries in both Open and Automated. Structure changes apply to both sheets and the Workload board. The Summary remains the original manual report. Structure changes clear the session’s cell undo history, and are recorded in the change log. Patterned fills are recreated with CSS; browser fonts and printing may differ slightly from Excel.
